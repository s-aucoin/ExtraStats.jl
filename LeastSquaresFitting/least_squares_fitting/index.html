Least Squares Fitting

These functions are specific to least squares fitting applications.

General Application

Least squares fitting using ordinary or generalized least squares is supported.

ExtraStats.fittest — Function
fittest(x, y; fittype = :OLS, fitmodel = nothing, p0 = [0.1, 0.1], figshow = true)

Perform a least squares fit with dependant variable y and independant x, test the significance of the trend, and create a plot to evaluate the residuals.

Default fitmodel is linear, and fittype ordinary least squares fit, :OLS, but optionally perform generalized least squares with fittype = :GLS.

Example

julia> using ExtraStats, Random

julia> Random.seed!(1234)

julia> x = 0.1:0.1:100

Fit Evaluation

Several functions for evaluating the goodness-of-fit of a given fit are provided.

ExtraStats.CalculateRMSE — Function
CalculateRMSE(e)

Calculate the Root-Mean-Square-Error of the vector of residuals e.

ExtraStats.r² — Function
r²(data, e)

Estimate the coefficient of determination of a fit to data with residuals e.

ExtraStats.χ²Test — Function
χ²Test(x, CDF, p; nbins=500, siglevel = 0.99)

Perform a χ² goodness-of-fit test of the null hypothesis that the data x come from a distribution with cumulative distribution function cdf with parameters p.

Optionally specify the number of bins nbins to separate x into, and the significance level siglevel to test against.

ExtraStats.KuiperTest — Function
KuiperTest(x, Fₕ)

Perform Kuiper's goodness-of-fit test of the null hypothesis that the data x come from CDF Fₕ.

Linear Fit Uncertainty

Specifically for linear fits, uncertainty on the slope and intercept can easily be estimated.

ExtraStats.linear_uncertainty — Function
linear_uncertainty(xi, yi, yhat, γ)

Calculate the confidence intervals at the γ level on the fit parameters of a linear regression on indpendent observations xi, dependent observations yi, and predicted dependent values yhat.

ExtraStats.SE_beta — Function
SE_beta(xi, yi, yhat)

Calculate the standard error of the slope of a linear regression with independent observations xi, dependent observations yi, and predicted dependent values yhat.

ExtraStats.SE_alpha — Function
SE_alpha(xi, yi, yhat)

Calculate the standard error of the intercept of a linear regression with independent observations xi, dependent observations yi, and predicted dependent values yhat.

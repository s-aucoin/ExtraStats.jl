Statistical Distributions

The mathematical definitions of several common (in Oceanography) probability density functions and their cumulative distribution functions are defined here for general use.

General Application

In addition, some generally-useful functions related to statistical distributions are provided.

ExtraStats.find_pdf_mode — Function
find_pdf_mode(pdf, x0; lr=nothing, up=nothing)

Estimate the mode of a probability density function pdf with initial guess x0.

ExtraStats.find_HDI — Function
find_HDI(pdf, samples; target_mass = 0.68)

Find the Highest Density Interval (Hyndman 1996) for the analytic probability density function pdf.

ExtraStats.transform_pdf — Function
transform_pdf(pdf, g, g⁻¹)

Complete a change of variables on an analytic probability density function pdf using the inverse g⁻¹ of the transformation function.

Normal Functions

ExtraStats.gaussian — Function
gaussian(x, A, μ, σ)

Calculate the value of a Gaussian function with amplitude A, centre μ, and standard deviation σ at x.

gaussian(x, p)

Calculate the value of a Gaussian function with parameter vector p at x.

ExtraStats.normal — Function
normal(x, μ, σ)

Calculate the value of a Normal function with centre μ and standard deviation σ at x.

normal(x, p)

Calculate the value of a Normal function with parameter vector p at x.

ExtraStats.∫Normaldx — Function
∫Normaldx(x)

Calculate the value of the integral of a Normal function at x.

ExtraStats.NormalCDF — Function
NormalCDF(x, μ, σ)

Calculate the CDF of a Normal pdf with centre μ and standard deviation σ at x.

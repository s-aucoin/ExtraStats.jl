bincounts(datax, binedgesx; makepdf=true)

Least Squares Fitting

ExtraStats.fittest — Function
fittest(x, y; fittype = :OLS, fitmodel = nothing, p0 = [0.1, 0.1], figshow = true)

Perform a least squares fit with dependant variable y and independant x, test the significance of the trend, and create a plot to evaluate the residuals.

Default fitmodel is linear, and fittype ordinary least squares fit, :OLS, but optionally perform generalized least squares with fittype = :GLS.

julia> x = 0.1:0.1:100

ExtraStats.χ²Test — Function
χ²Test(x, CDF, p; nbins=500, siglevel = 0.99)

Perform a χ² goodness-of-fit test of the null hypothesis that the data x come from a distribution with cumulative distribution function cdf with parameters p.

Optionally specify the number of bins nbins to separate x into, and the significance level siglevel to test against.
